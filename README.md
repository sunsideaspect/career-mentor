# Вступ до ВВНЗ 2027

Статичний інформаційний лендинг кампанії для Криворізького району.

## Локальний запуск

```powershell
python -m http.server 8080
```

## Налаштування

Усі змінні середовища кампанії винесені в `config.js`.

Перед production:

1. Підтвердити офіційний телефон та організацію.
2. Підключити перевірений endpoint форми з серверною автентифікацією, валідацією та журналом згоди.
3. Вказати `consultationFormEndpoint` у deployment-конфігурації. У репозиторії він навмисно порожній.
4. Додавати аналітику лише без ПІБ, телефонів, школи й медичних даних.
5. Після 01.01.2027 оновити правила та дату їх перевірки.

До підключення безпечного endpoint форма не збирає даних і показує офіційний телефон.
